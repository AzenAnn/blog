## 资料

以下内容来自AI搜索和搜素引擎：

- [R 官方站](https://www.r-project.org/)：装软件、看版本、进官方文档
- [R 官方中文手册镜像](https://cran.r-project.cn/manuals.html)：中文更友好，适合打基础
- [An Introduction to R](https://rstudio.github.io/r-manuals/r-intro/)：最硬核、最稳的 base R 主线
- [R Data Import/Export](https://rstudio.github.io/r-manuals/r-data/Introduction.html)：导入导出和编码问题专治期末细节题
- [R for Data Science (2e)](https://r4ds.hadley.nz/)：现代数据处理和可视化主线
- [Posit Cheatsheets](https://posit.co/resources/cheatsheets/)：有中文翻译，考前速刷非常好用
- [Posit Cheatsheets HTML](https://rstudio.github.io/cheatsheets/)：可直接查 `dplyr / tidyr / ggplot2`
- [swirl](https://swirlstats.com/)：在 R 里交互式学习
- [swirl 的 R Programming 课程](https://swirlstats.com/scn/rprog.html)：很适合 0 基础
- [CS50’s Introduction to Programming with R](https://cs50.harvard.edu/r/)：结构非常清晰，适合系统推进
- [Harvard Extension 的课程描述](https://coursebrowser.dce.harvard.edu/course/introduction-to-programming-with-r/)：能看出高校 R 课常见考点范围
- [Ohio State Basic R 课程页](https://stat.osu.edu/courses/stat-5731)：能看出“基础 R + 可视化/变换/组织数据”是常规主线
- [Cornell Data Science with R syllabus](https://info2951.infosci.cornell.edu/course-syllabus.html)：能看出期末通常还会考工作流、作业、测验、累计考试
- [MIT OCW 的 R 入门材料](https://ocw.mit.edu/courses/15-071-the-analytics-edge-spring-2017/pages/an-introduction-to-analytics/working-with-data-an-introduction-to-r/)：适合补“上手感”
