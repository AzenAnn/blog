## 1. 类与对象：这节课不是在学“字符串”，而是在学“面向对象入口”

> [!summary] 一句话结论
> `std::string` 的意义，不只是让你处理字符串更方便，而是让你第一次感受到：**C++ 会把复杂的底层细节封装进类里，让你通过对象接口直接使用。**

### 本质解释

C 风格字符串本质是：

```cpp
char s[] = "hello";
```

它背后依赖的是：

- 字符数组
- `'\0'` 结尾
- 手动控制空间大小
- 容易越界
- 容易忘记结尾字符
- 容易在拼接、拷贝、修改时出错

C++ 提供 `std::string`，目的是把这些细节封装起来。

你不需要自己管理：

- 空间增长
- 字符串长度
- 拼接后的容量是否够
- 很多低级内存细节

这就是**封装**的直观体现。

### 一个最重要的思想

> [!note] 你现在就要建立的认知
> `std::string` 不是“字符数组换皮”，而是“一个负责管理字符串资源和行为的类”。

---

## 2. 为什么 C++ 要引入 `std::string`

### C 风格字符串的问题

```cpp
char s1[10] = "hello";
char s2[10] = "world";
strcat(s1, s2);   // 有越界风险
```

这里的风险有：

- `s1` 空间未必够
- `strcat` 不会帮你自动扩容
- 写错长度很容易出 bug

### `std::string` 的写法

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s1 = "hello";
    std::string s2 = "world";
    std::string s3 = s1 + " " + s2;
    std::cout << s3 << '\n';
}
```

输出：

```text
hello world
```

### 这在实际中有什么用

`std::string` 在实际开发中非常常见：

- 处理用户名、密码、邮箱、学号
- 处理日志文本
- 处理文件路径
- 处理网络消息
- 处理命令行输入
- 处理题目里的字符串算法

## 3. `std::string` 对象的创建与初始化

> [!summary] 一句话结论
> C++ 里定义对象时，最重要的不是“先有个变量”，而是“对象怎么被初始化”。

### 常见初始化方式

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s1;
    std::string s2 = "c++";
    std::string s3 = s2;
    std::string s4(5, 's');

    std::cout << "[" << s1 << "]\n";
    std::cout << s2 << '\n';
    std::cout << s3 << '\n';
    std::cout << s4 << '\n';
}
```

输出大致是：

```text
[]
c++
c++
sssss
```

### 你必须看懂每个对象

| 代码 | 含义 |
|---|---|
| `std::string s1;` | 默认构造，空字符串 |
| `std::string s2 = "c++";` | 用 C 字符串初始化 |
| `std::string s3 = s2;` | 用另一个字符串初始化 |
| `std::string s4(5, 's');` | 构造 5 个 `'s'` 组成的字符串 |

### 严谨补充

课件里会强调“创建对象”，这是为了提醒你：C++ 对象通常会经历初始化过程。

更严谨地说：

- `std::string s2 = "c++";` 也是定义变量
- 但它同时也是**对象初始化**
- 在 C++ 里，“初始化”比“先占个变量名”重要得多

## 4. `std::string` 常用运算符

> [!summary] 一句话结论
> `std::string` 之所以好用，一个重要原因是它对很多运算符做了重载。

### 1. 拼接：`+` 和 `+=`

```cpp
std::string s1 = "hello ";
std::string s2 = "sysu";
std::string s3 = s1 + s2;
s1 += "computer";
```

#### 应用场景

- 拼接欢迎语
- 拼接路径
- 拼接日志信息
- 拼接题目中的结果字符串

---

### 2. 比较：`== != < >`

```cpp
std::string a = "apple";
std::string b = "banana";

if (a < b) {
    std::cout << "apple comes before banana\n";
}
```

#### 关键点

字符串比较默认是**字典序比较**。

例如：

- `"abc" < "abd"` 为真
- `"9" > "10"` 也可能为真，因为比较的是字符顺序，不是数字大小

> [!warning] 常见误区
> 不要把字符串比较和数值比较混为一谈。

---

### 3. 下标访问：`[]`

```cpp
std::string s = "sysu";
std::cout << s[0] << '\n';  // s
s[0] = 'S';
std::cout << s << '\n';     // Sysu
```

#### 为什么能修改

因为 `operator[]` 返回的是字符引用，所以它能作为左值。

#### 应用场景

- 改首字母大小写
- 遍历字符串
- 逐字符判断

> [!warning] 常见坑
> `s[index]` 不做越界检查。下标不合法会产生未定义行为。
> 如果你想要带检查的访问，可以后续学 `s.at(index)`。

## 5. `std::string` 常用成员函数

---

### 5.1 `length()` / `size()`

```cpp
std::string s = "sysu-computer";
std::cout << s.length() << '\n';
```

#### 结论

- 返回字符串长度
- 返回类型通常是 `size_t`

#### 应用

- 循环遍历
- 判断空串
- 做边界检查

---

### 5.2 `c_str()`

```cpp
std::string s = "hello";
const char* p = s.c_str();
std::cout << p << '\n';
```

### 它是干什么的

把 `std::string` 转成 C 风格字符串，方便和旧的 C 接口协作。

#### 实际应用

比如某些旧库函数需要 `const char*`：

```cpp
std::string filename = "data.txt";
// 某些 C 风格 API 需要 filename.c_str()
```

> [!warning] 常见坑
> `c_str()` 返回的指针依赖于原字符串对象。
> 如果字符串被修改、销毁，这个指针就可能失效。

---

### 5.3 `find()` 和 `rfind()`

```cpp
std::string s = "sysu-computer";
auto pos = s.find("computer");
std::cout << pos << '\n';
```

#### 本质

- `find()`：从左往右找第一次出现的位置
- `rfind()`：从右往左找

#### 你必须会写的安全判断

```cpp
std::string s = "sysu-computer";
auto pos = s.find("math");

if (pos == std::string::npos) {
    std::cout << "not found\n";
}
```

> [!warning] 非常重要
> 没找到时，`find()` 返回的不是 `-1`，而是 `std::string::npos`。

#### 实际应用

- 查找子串
- 查找文件扩展名
- 查找邮箱中的 `@`
- 查找某个关键词是否出现

---

### 5.4 `replace()`

```cpp
std::string s = "sysu-computer";
auto pos = s.find("computer");
if (pos != std::string::npos) {
    s.replace(pos, 8, "software");
}
std::cout << s << '\n';
```

输出：

```text
sysu-software
```

#### 实际应用

- 文本替换
- 敏感词替换
- 路径片段替换
- 配置字符串修正

---

### 5.5 `append()`、`insert()`、`erase()`、`clear()`

```cpp
std::string s = "ysu";
s.insert(0, 1, 'S');
s.append(1, '-');
s.append("computer");
std::cout << s << '\n';   // S-ysucomputer

s.erase(2, 3);
std::cout << s << '\n';

s.clear();
std::cout << s.length() << '\n';
```

#### 这些操作分别适合什么

| 函数 | 作用 | 常见用途 |
|---|---|---|
| `append` | 追加到末尾 | 拼接后缀 |
| `insert` | 插入到中间 | 插入分隔符 |
| `erase` | 删除一段 | 去掉多余字符 |
| `clear` | 清空字符串 | 重置状态 |

---

### 5.6 `substr()`

```cpp
std::string s = "Sysu-Computer";
std::string left = s.substr(0, 4);
std::cout << left << '\n';
```

输出：

```text
Sysu
```

#### 实际应用

- 提取前缀
- 提取后缀
- 提取文件扩展名
- 截出邮箱域名

---

### 5.7 `compare()`

```cpp
std::string s = "Computer";
if (s.compare("Computer") == 0) {
    std::cout << "equal\n";
}
```

> [!note] 严谨补充
> `compare()` 的结果应该理解为：
> - 小于 0：前者更小
> - 等于 0：相等
> - 大于 0：前者更大
>
> 不要死记成一定返回 `-1、0、1`。

## 6. 例题精讲 1：提取邮箱域名

> [!question] 题目
> 输入一个邮箱字符串，如 `alice@sysu.edu.cn`，输出域名部分，也就是 `sysu.edu.cn`。

### 思路拆解

1. 找到 `@` 的位置
2. 从 `@` 后面开始截取子串
3. 如果没有 `@`，说明格式不合法

### 代码

```cpp
#include <iostream>
#include <string>

int main() {
    std::string email;
    std::getline(std::cin, email);

    auto pos = email.find('@');
    if (pos == std::string::npos || pos + 1 >= email.length()) {
        std::cout << "invalid email\n";
        return 0;
    }

    std::string domain = email.substr(pos + 1);
    std::cout << domain << '\n';
}
```

### 这题训练什么

- `find`
- `substr`
- 边界判断
- `npos` 的正确使用

### 实际应用

- 邮箱格式检查
- 用户信息解析
- 日志分析
- 文本预处理

## 7. C 标准库在 C++ 中怎么用

> [!summary] 一句话结论
> C++ 不是和 C 完全割裂的，它保留了对很多 C 标准库的支持，但更推荐你用 C++ 风格的头文件和命名空间。

### 常见写法

| C 风格 | C++ 更推荐 |
|---|---|
| `<ctype.h>` | `<cctype>` |
| `<assert.h>` | `<cassert>` |
| `<string.h>` | `<cstring>` |
| `<stdio.h>` | `<cstdio>` |

### 为什么推荐 C++ 风格头文件

因为它们更自然地和 `std` 命名空间配合。

例如：

```cpp
#include <cctype>
#include <iostream>

int main() {
    char ch = 'A';
    std::cout << std::tolower(ch) << '\n';
}
```

## 8. 例题精讲 2：回文字符串判断

> [!question] 题目
> 判断一句话是否为回文，忽略空格、标点和大小写。
>
> 例如：
> - `A man, a plan, a canal: Panama.`
> - `No lemons, no melon.`

### 为什么不能直接用 `cin >> s`

因为 `cin >> s` 读到空格就停了。

而这类句子里有：

- 空格
- 标点
- 多个单词

所以必须用：

```cpp
std::getline(std::cin, s);
```

---

### 正确解法分两步

#### 第一步：预处理

目标：

- 去掉非字母字符
- 把大写变小写

#### 第二步：判断是否回文

用双指针：

- 左边一个指针
- 右边一个指针
- 逐步向中间靠拢
- 有一个字符不同就不是回文

---

### 代码

```cpp
#include <cassert>
#include <cctype>
#include <iostream>
#include <string>

std::string low_alpha(const std::string& str) {
    std::string result;
    for (char ch : str) {
        if (std::isalpha(static_cast<unsigned char>(ch))) {
            result.append(1, static_cast<char>(std::tolower(static_cast<unsigned char>(ch))));
        }
    }
    return result;
}

bool test_palindrome(const std::string& str) {
    int left = 0;
    int right = static_cast<int>(str.length()) - 1;

    while (left < right) {
        if (str[left] != str[right]) {
            return false;
        }
        ++left;
        --right;
    }
    return true;
}

int main() {
    std::string s;
    std::getline(std::cin, s);

    s = low_alpha(s);

    if (!s.empty()) {
        assert(s.front() == s.back());
    }

    if (test_palindrome(s)) {
        std::cout << "Palindrome\n";
    } else {
        std::cout << "Not palindrome\n";
    }
}
```

---

### 这段代码里你必须看懂的点

#### `const std::string& str`

这四个部分每个都重要：

| 片段 | 含义 |
|---|---|
| `std::string` | 参数类型是字符串对象 |
| `&` | 引用传递，不拷贝整个字符串 |
| `const` | 函数承诺不修改传入字符串 |
| `str` | 参数名 |

#### 为什么这样写最合适

如果写成：

```cpp
std::string low_alpha(std::string str)
```

也能运行，但会额外复制一份字符串，成本更高。

所以这里用：

```cpp
const std::string&
```

是非常典型的工程写法。

---

### 这题训练什么能力

- `getline`
- `std::string`
- `find/append`
- C 标准库字符处理函数
- `const &` 参数设计
- 双指针思维

---

### 实际应用

这个思想在实际里很常见：

- 搜索引擎预处理文本
- 敏感词过滤前统一大小写
- 用户输入清洗
- 数据标准化

## 9. `const` 和 `constexpr`：这是本讲最容易半懂半不懂的点

> [!summary] 一句话结论
> `const` 主要强调“只读”，`constexpr` 主要强调“编译期就能确定的常量表达式”。

---

### 9.1 先看课件里的核心现象

```cpp
#include <array>

void dis_1(const int x) {
    // 错误：x 不是编译期常量表达式
    // std::array<int, x> arr{};
}

void dis_2() {
    const int x = 5;
    std::array<int, x> arr{};
}
```

#### 为什么 `dis_1` 不行

`dis_1` 里的 `x` 是函数参数。

即使它是 `const`，它也只是：

- 只读
- 但值要等到运行时才知道

所以它不是编译期常量表达式。

#### 为什么 `dis_2` 可以

`dis_2` 里的 `x`：

- 是 `const`
- 且用字面量 `5` 初始化
- 编译器在编译时就知道它的值

所以这里能作为模板参数使用。

---

### 9.2 你应该怎么理解

#### `const`

表示“通过这个名字，不能改这个值”。

```cpp
const int x = 10;
// x = 20;  // 错误
```

#### `constexpr`

表示“这个值或函数结果在编译期就应该能确定”。

```cpp
constexpr int n = 5;
std::array<int, n> arr{};
```

---

### 9.3 最推荐的学习习惯

> [!tip] 实战建议
> - 表达“只读”时，优先想 `const`
> - 表达“编译期常量”时，优先想 `constexpr`

---

### 9.4 典型例子

#### 例子 1：只读参数

```cpp
void print_len(const std::string& s) {
    std::cout << s.length() << '\n';
}
```

这里 `const` 的意义是：

- 我只读，不修改
- 调用者更放心
- 编译器也能帮你检查

---

#### 例子 2：编译期数组大小

```cpp
#include <array>

constexpr int kSize = 8;
std::array<int, kSize> arr{};
```

这里如果换成运行期才知道的值，就不行。

---

#### 例子 3：`constexpr` 函数

```cpp
constexpr int square(int x) {
    return x * x;
}

std::array<int, square(3)> arr{};
```

如果参数在编译期可知，那么 `square(3)` 的结果也能在编译期确定。

---

### 9.5 实际应用

| 场景 | 推荐写法 |
|---|---|
| 函数只读参数 | `const T&` |
| 不允许修改的成员函数参数 | `const` |
| 固定配置值 | `constexpr` |
| 数组大小、模板参数 | `constexpr` |
| 编译期辅助计算 | `constexpr` 函数 |

## 10. `auto`：不是偷懒，而是让代码更清晰

> [!summary] 一句话结论
> `auto` 的本质不是“我懒得写类型”，而是“编译器已经能从初始化表达式推导出类型，所以我把注意力放在值和逻辑上”。

### 最基本例子

```cpp
auto x = 5;      // int
auto y = 3.14;   // double
auto z = 'a';    // char
```

---

### 为什么 `auto` 很有用

#### 例子 1：迭代器类型太长

```cpp
std::vector<int> v{1, 2, 3};
std::vector<int>::iterator it = v.begin();
```

可以写成：

```cpp
auto it = v.begin();
```

#### 例子 2：范围 for

```cpp
std::vector<int> v{1, 2, 3};

for (auto x : v) {
    std::cout << x << ' ';
}
```

---

### 你必须知道的规则

#### 1. `auto` 必须初始化

```cpp
auto x = 5;   // 对
auto y;       // 错
```

#### 2. 同一行多个 `auto` 变量必须推导成同一类型

```cpp
auto a = 5, b = 6;      // 对
// auto x = 5, y = 3.14; // 错
```

#### 3. `auto` 常用于局部变量，不要乱用到让代码更难懂

如果类型明明很清楚，写不写 `auto` 都行。

如果用了 `auto` 反而让别人看不出含义，那就不好。

---

### 一个很重要但课件没展开的坑

> [!warning] `auto` 会丢掉一部分修饰信息
> `auto` 推导时，默认会忽略顶层 `const`，也不会保留引用语义，除非你明确写出来。

```cpp
int x = 10;
int& rx = x;
auto a = rx;     // a 是 int，不是 int&
auto& b = rx;    // b 才是 int&
```

再看：

```cpp
const int c = 20;
auto p = c;         // p 是 int
const auto q = c;   // q 是 const int
```

#### 你现在先记住这条就够了

- 想复制一份：`auto`
- 想保留引用：`auto&`
- 想只读引用：`const auto&`

---

### `auto` 的实际应用

| 场景 | 推荐写法 |
|---|---|
| 迭代器 | `auto it = v.begin();` |
| 范围 for | `for (auto x : v)` |
| 只读遍历大对象 | `for (const auto& x : v)` |
| 类型太长但右侧很清楚 | 用 `auto` |

---

## 11. `bool`：别再拿 `int` 当真假值硬凑

> [!summary] 一句话结论
> 在 C++ 里，`bool` 是正式的基础类型，应该用来表达真假，而不是继续延续 C 风格的“0 表示假，非 0 表示真”的习惯。

### 最基本写法

```cpp
bool ok = true;
bool fail = false;
```

### 典型用法

```cpp
std::string s = "level";
bool is_same = (s.front() == s.back());

if (is_same) {
    std::cout << "first and last are equal\n";
}
```

---

### 为什么 `bool` 重要

它会让代码的意图更清楚。

对比：

```cpp
int flag = 1;
if (flag) { ... }
```

和

```cpp
bool is_valid = true;
if (is_valid) { ... }
```

第二种明显更容易读懂。

---

### 实际应用

- 判断输入是否合法
- 判断查找是否成功
- 判断回文是否成立
- 判断用户是否登录
- 判断文件是否打开成功

---

### 工程建议

> [!tip] 推荐习惯
> - 返回逻辑结果的函数，优先返回 `bool`
> - 条件变量尽量起成 `is_xxx`、`has_xxx`、`can_xxx` 这种名字
> - 不要写 `if (ok == true)`，直接写 `if (ok)` 即可

## 14. 高频误区

> [!warning] 这些错很常见
> - 把 `std::string` 当成“自动带 `\0` 的字符数组”，没理解它是类对象
> - 用 `find()` 之后直接拿结果当下标，不判断是否等于 `npos`
> - 以为 `compare()` 一定返回 `-1/0/1`
> - 以为 `const` 就一定等于“编译期常量”
> - 看到 `auto` 就无脑用，导致代码更难读
> - 继续用 `int` 表达真假，而不是 `bool`
> - 处理一句完整输入时还用 `cin >> s`，结果遇到空格就截断
